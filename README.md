## 🚀 快速开始

请按照以下步骤快速安装和运行项目。

### 先决条件

在开始之前，请确保你的系统已安装以下软件：
*   Node.js >= 14
*   npm >= 6

### 安装

1.  克隆仓库：
    ```bash
    git clone https://github.com/greenwich0807/Simon.git
    ```
2.  进入项目目录：
    ```bash
    cd Simon
    ```
3.  安装依赖：
    ```bash
    npm install
    ```

### 使用方法

1.  启动开发服务器：
    ```bash
    npm start
    ```
2.  在浏览器中打开 `http://localhost:3000` 查看结果。
